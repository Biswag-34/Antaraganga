The clinical people, spaces and landscapes are AI-generated representative imagery. The hospital hero is an adapted architectural visual. These assets do not document actual people, facilities, clinical outcomes, branch addresses or acquired equipment.

Tablet files reuse the best-fitting desktop or mobile composition, with the source shown on each tile. Complete contains PNG originals; Web contains website-ready files. Buttons, text, budgets, tabs, forms and hotspots should remain HTML.
